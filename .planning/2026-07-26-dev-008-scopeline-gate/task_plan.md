## 约束

- 本任务不修改 Release baseline，不创建 Seal、tag、GitHub Release 或部署。
- PRD 只读；`generated/spec/` 只允许由生成器写入。
- 未知适用性、规则、版本或权限默认阻断。
- 不把 ScopeLine 身份、任务分配和代表性覆盖混为一体。
- 不在任务卡 READY 前开始业务编码。
