# DEV-009 不可变数量流水与并发预留

## 目标

在不推进发布、Seal 或部署的前提下，从 PRD 收敛 `ATC-QTY-001` 的最小业务切片；只有任务卡经用户明确批准且 `ready` 返回 READY 后，才实现不可变数量流水、守恒校验、并发预留和冲销重记。

## 阶段

1. [completed] 完成规格、来源、影响、数量流水语义和实现边界核对。
2. [completed] 确认 OD-010 计量维度最小口径并取得用户对精简 DEV-009 业务基线的明确批准。
3. [completed] 创建批准的后继规格与任务卡，生成派生物并使精确版本任务卡返回 READY。
4. [completed] 在 allowed_paths 内实现领域逻辑、公共契约、持久化/API、审计和可用量查询端口。
5. [completed] 补齐正向、反向、边界、权限、并发、恢复、审计和回归测试。
6. [in_progress] 执行完整门禁，确认二次生成 written=0，并等待提交/推送指令。（门禁全部通过，仅剩等待用户提交/推送指令。）

## 约束

- 本任务不修改 Release baseline，不创建 Seal、tag、GitHub Release 或部署。
- PRD 只读；`generated/spec/` 只允许由生成器写入。
- 未知适用性、规则、版本或权限默认阻断。
- 不把数量流水、任务分配（TestObjectAllocation）和物理谱系混为一体（OPS-LIN-001 关系分离）。
- 不在任务卡 READY 前开始业务编码。
- 遵循 BP-018：不得对非破坏性或不可合理计量场景制造伪精确数量。
