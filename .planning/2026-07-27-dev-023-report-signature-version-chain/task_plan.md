# DEV-023 报告签名与不可变版本链（ATC-RPT-002）

报告链后半。OD-011（CNAS/CMA + 电子签名法：重认证 + 签署意图 + 绑定内容哈希；已签发版本永久保留）与 OD-022（版本链取代：更正/补充产生新版本，撤回改状态，作废终止链，替代以新报告号）已决，无需新决策。

## 关键设计

- **内容哈希**：对报告版本的规范化快照（报告号+版本号+每行的采用目标/组版本/范围分区/认可判定/贡献链引用，按行号排序）算 SHA-256。签名绑定该哈希；快照与哈希都是不可变事实。
- **SEC-SIGN-001 三要素**：签发请求必须携带重新认证证据引用、显式签署意图文本、期望内容哈希；期望哈希与服务端重算不符即拒绝（这同时实现 SEC-SIGN-002：内容变了哈希就变，旧签名对不上）。
- **签发前置**：必须存在 IReportIssuanceGatePort ALLOWED 且该评估覆盖当前全部行（复用 DEV-022 的新鲜度判别）。
- **五种受控动作**（OD-022）：CORRECTION/SUPPLEMENT 产生新版本（需影响评估引用）、WITHDRAWAL 标记指定版本停止被依赖、VOID 终止整链、SUPERSESSION 以新报告号记录取代关系。
- **RPT-VERS-004**：验证页读模型按版本号返回该版本本身与其历史状态，旧版本永不被新内容替换。
