## 📚 技术栈和模式

### 架构模式
- **模块化单体**：每个模块独立但在同一进程
- **领域驱动设计**：清晰的领域层、应用层、基础设施层
- **事件驱动**：审计和发件箱（Outbox 模式）
- **版本固定引用**：所有跨模块引用都固定版本

### 数据库设计
- **PostgreSQL**：主数据库
- **追加式不可变**：触发器阻止 UPDATE/DELETE
- **审计字段**：created_at/by, updated_at/by, deleted_at/by
- **版本控制**：乐观并发控制 (expected_version)

### API 设计
- **REST**：标准 HTTP 方法
- **JSON**：序列化格式
- **错误码**：结构化错误响应
- **权限验证**：能力基础访问控制 (CBAC)

### 质量保证
- **规格驱动**：所有功能都有规格
- **工具验证**：specgen 工具链
- **契约测试**：序列化形状冻结
- **架构边界测试**：模块隔离验证
